O que é Flexbox?

Flexbox é um modelo de layout do CSS utilizado para organizar elementos em uma linha ou coluna. Ele facilita a criação de layouts responsivos e o alinhamento dos elementos. Distribui o espaço entre os elementos automaticamente. Alinha itens na horizontal ou na vertical. Facilita a criação de páginas que se adaptam a telas de celulares e computadores.

.container {
  display: flex;
}

1. display: flex

É a propriedade que transforma um elemento em um Flex Container.

.container {
  display: flex;
}
A
B
C
display: flex

O contêiner se comporta como um elemento de bloco (block).
Ocupa 100% da largura disponível na linha, forçando uma quebra de linha antes e depois dele.
Outros elementos ao redor não conseguem ficar na mesma linha que este contêiner, mesmo que ele tenha poucos itens dentro.

display: inline-flex

O contêiner se comporta como um elemento em linha (inline-block).
Ocupa apenas o espaço necessário para acomodar seus itens internos.
Permite que outros elementos fiquem lado a lado na mesma linha, caso haja espaço.

O primeiro item fica grudado na borda inicial e o último fica grudado na borda final.
O espaço livre restante é dividido igualmente apenas entre os itens do meio. Não há espaço extra nas extremidades externas.

space-around

1
2
3
justify-content: space-around;

O espaço livre é dividido de forma igual ao redor de cada item.
Isso faz com que cada item receba meia porção de espaço nas pontas (início e fim) e uma porção inteira (o dobro das pontas) entre um item e outro. Os itens não ficam colados nas bordas do contêiner.

space-evenly

1
2
3
justify-content: space-evenly;

O espaço livre é dividido em partes perfeitamente iguais.
O espaço entre qualquer item adjacente, bem como o espaço antes do primeiro item e depois do último item, tem exatamente o mesmo tamanho.

4. align-items

Controla o alinhamento dos elementos no eixo transversal.

Se a direção é flex-direction: row (linha), o eixo principal é horizontal e o eixo transversal é vertical. align-items mexe na altura (em cima/baixo).
Se a direção é flex-direction: column (coluna), o eixo principal é vertical e o eixo transversal é horizontal. align-items mexe na largura (esquerda/direita).

Propriedades dos Flex Items

Algumas propriedades são aplicadas diretamente aos elementos filhos do Flex Container.

8. flex-grow

Define quanto um item pode crescer para ocupar o espaço disponível.

Espaço restante:Ela só age se houver espaço livre sobrando no contêiner após posicionar todos os itens.
Valores numéricos:Usa números sem unidade (o padrão é 0, que significa não crescer). Valores negativos não funcionam.
Proporção: Se múltiplos itens tiverem flex-grow maior que zero, o espaço livre é dividido proporcionalmente entre eles com base nesses números.

flex-grow: 0 (Padrão): O item mantém o seu tamanho original e não se expande, mesmo que haja espaço sobrando.
flex-grow: 1 em todos os itens: Todos os itens dividem o espaço livre de forma igual, crescendo para preencher o contêiner por completo.
Proporções diferentes (ex: 1 e 2): Um item com flex-grow: 2 vai crescer o dobro em relação a um item com flex-grow: 1, recebendo o dobro do espaço livre disponível.

1
2
3
flex-grow: 1;

9. flex-shrink

Define quanto um item pode diminuir quando não existe espaço suficiente.

Valor padrão: O valor padrão é 1, o que significa que o item tem permissão para encolher de forma proporcional caso falte espaço.
Impedir redução (0): Se você definir flex-shrink: 0, o elemento nunca vai diminuir além do seu tamanho inicial, mesmo que estoure os limites do contêiner.
Proporção de encolhimento (número maior): Valores maiores (como 2 ou 3) fazem o item encolher mais rápido e de forma mais acentuada do que os seus irmãos que possuem um fator menor.

1
2
3
flex-shrink: 1;

Propriedade Função Principais valores

flex-basis Tamanho inicial auto, px, %, rem...
